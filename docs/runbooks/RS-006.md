## Composer

El ciclo de vida de Composer está en `docs/runbooks/BATCH_LIFECYCLE.md`.
El entorno `retailsmart-batch` requiere validación `RUNNING` antes de considerarse
listo. No se ejecutan DAGs automáticamente.

## Límites

No se crean clusters persistentes Dataproc, jobs Dataflow ni servicios Cloud Run
sin código/artefactos definidos para ellos. Las tecnologías y sus
`archimate_id` provienen de `architecture/inventory/view08-gcp-mapping.csv`.
