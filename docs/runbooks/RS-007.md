# RS-007 — Fixtures streaming

## Ejecución local

```bash
python3 scripts/fixtures/generate_streaming_fixtures.py
python3 -m unittest tests.test_streaming_fixtures -v
bash scripts/verify-local.sh
```

Se generan seis envelopes JSON deterministas en
`tests/fixtures/streaming/`. RS-007 no publica mensajes ni modifica GCP.

## Verificación

Cada fixture debe tener `producer_id`, `event_id`, `trace_id`, timestamps UTC,
payload compatible con RS-002 y `quality.is_projected_defect=false`. La
publicación en Pub/Sub pertenece a los incrementos posteriores.
