# RS-008 — Raw Event Writer

## Prueba local

```bash
python3 -m unittest tests.test_raw_event_writer -v
bash scripts/verify-local.sh
```

El writer conserva el envelope original bajo
`streaming/raw/producer_id=<producer>/dt=<YYYY-MM-DD>/event_id=<event>.json`.
Una repetición idéntica devuelve `duplicate`; el mismo `event_id` con contenido
diferente se rechaza. No transforma ni publica mensajes y no modifica GCP.

La integración con Pub/Sub/Dataflow queda para los incrementos de procesamiento;
este entregable fija la semántica de persistencia Bronze immutable.
