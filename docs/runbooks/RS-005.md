# RS-005 — Mensajería Pub/Sub

```bash
export CLOUDSDK_CONFIG=/tmp/retailsmart-gcloud
bash scripts/tests/test_pubsub.sh
bash scripts/gcp/04-pubsub.sh --dry-run
bash scripts/gcp/04-pubsub.sh
bash scripts/gcp/04-pubsub.sh
```

El script conserva topics y suscripciones existentes. La rama de eventos
mantiene suscripciones independientes para raw y Dataflow; insights y auditoría
tienen consumidores separados.

En Cloud Console → Pub/Sub, confirmar topics `events`, `insights` y `audit`, sus
suscripciones, ack deadline de 60 segundos, expiración de 7 días en las nuevas
suscripciones y labels de laboratorio. No se publican mensajes ni se despliegan
consumidores en RS-005.
