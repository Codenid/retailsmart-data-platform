# RS-009 — Ingesta streaming hacia Silver

## Objetivo

Validar y normalizar eventos válidos desde el Tópico Eventos Retail hacia Silver
mediante una demo académica mínima y verificable.

## Componentes ArchiMate

- Ingesta Streaming Dataflow: `id-2fe58104d85b4e32963decf9d8dba120`.
- Stream Processor Ingesta: `id-48761e22dab94d7991a6b735fbfd1c36`.
- Silver Event Writer: `id-ade5a96bb65a46f2b3cdd5e9eff89929`.
- Silver Eventos Curados: `id-7dc51a4339184e2f82ff52d870a1d5f8`.

## Fase happy path

Evento válido llega a Silver sin alterar Bronze. Cada evento se escribe como un
objeto JSON individual bajo `eventos/demo/DEMO_RUN_ID/EVENT_ID.json`.
Deduplicación, cuarentena, DLQ y auditoría quedan fuera del recorrido ejecutado.

Las ramas de cuarentena/DLQ y auditoría se mantienen como rutas preparadas para
ampliarse después de validar el recorrido principal.

## Prueba

Pruebas locales del contrato, normalización y ruta estable del escritor. En GCP
se debe publicar un evento, leer el objeto Silver real, comprobar Bronze de
forma independiente y cancelar el job con estado `CANCELLED`.
